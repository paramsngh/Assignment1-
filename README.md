Overview

This project is a web application developed using Node.js and Express that allows users to create, view, and delete campus events. The goal of the application is to provide TMU students with a simple interface to reserve campus spaces for events.

The application demonstrates client-server communication through a REST API, where users can send GET, POST, and DELETE requests to manage event data. Instead of using a database, events are simulated using a JSON object stored on the server, as required for this assignment.


Future extensions of this application could include:

 - Integrating a database for storage
 - Adding user authentication
 - Preventing booking conflicts
 - Enhancing the UI with React
